# AgentRoom — registry map

A read-only copy of the AgentRoom registry: 71 records with a status, provenance and a visible judge.

Generated from the private registry by `python3 -m ar build`; `index.html` is a single self-contained
file (fonts and data inlined), so it opens with or without a server.

Legend: **c** checked · **w** in work · **j** proposed · **r** refuted · **b** retired · **n** not faithful.
